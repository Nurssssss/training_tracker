# Спецификация проекта — Training Tracker

> Полный текст ТЗ: [`ТЗ_финальный_проект.pdf`](./ТЗ_финальный_проект.pdf)

## Идея
Мобильное приложение для отслеживания силовых тренировок: пользователь создаёт тренировки, добавляет упражнения с подходами и повторениями, ведёт историю.

## Целевая аудитория
Люди, регулярно занимающиеся в зале или дома, кому важно фиксировать прогресс (рабочий вес, объём, частоту).

## Проблема
Заметки в телефоне неудобны, готовые приложения перегружены или платные. Нужно простое локальное+облачное решение с историей и аналитикой.

## Основные сценарии
1. **Регистрация / вход** через Supabase Auth (email + пароль).
2. **Создать тренировку** — название, дата, заметка.
3. **Добавить упражнения в тренировку** — название, целевая группа мышц.
4. **Записать подходы** — повторения и вес для каждого подхода упражнения.
5. **Просмотр истории** — список прошедших тренировок, открытие любой.
6. **Удаление / редактирование** тренировок и упражнений.

## Функциональные требования (из ТЗ)
- 3–4 экрана с навигацией (GoRouter).
- State management: BLoC/Cubit.
- Хранение данных: Supabase.
- Минимум одна форма с валидацией.
- Архитектурное разделение: models, services/repositories, views, widgets.
- Git с историей коммитов по фичам.

## Нефункциональные требования
- Поддержка iOS и Android.
- Тёмная и светлая тема (опционально).
- Авторизация обязательна перед доступом к данным.

## Экраны (минимум)
1. **AuthScreen** — вход / регистрация.
2. **WorkoutsListScreen** — список тренировок пользователя.
3. **WorkoutDetailScreen** — детали тренировки + добавление упражнений и подходов.
4. **HistoryScreen** — история тренировок (опц. графики/статистика).

## Что НЕ входит в MVP
- Push-уведомления.
- Оффлайн-синхронизация.
- Социальные функции (шаринг тренировок).
- Видео/фото в упражнениях.
